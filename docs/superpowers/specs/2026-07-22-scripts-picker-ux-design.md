# Выбор скрипта звонка: UX + комментарий

**Дата:** 2026-07-22
**Статус:** утверждён

## Проблема

`ScriptsDialog` показывает только дерево заголовков скриптов. Поля `Description`,
`Steps`, `Questions`, `Tips` и `Category.Color` есть в модели `CallScript`, но
в интерфейс не выводятся — оператор выбирает скрипт вслепую по названию и не
может прочитать сам скрипт во время разговора.

Второе: `CdrLogRequest.Note` объявлен в модели и поддержан бэкендом, но нигде
не заполняется. Оператор не может оставить комментарий к звонку.

Третье: `ActiveCallView` и `RecentsView` дублируют последовательность
«зарегистрировать скрипт → пометить звонок как залогированный».

## Решение

Диалог остаётся чистым picker'ом: он возвращает выбор (скрипт + комментарий),
а POST в CDR делают вызывающие через общий метод сервиса. Диалог не знает про
резолв `uniqueId` и про `LoggedCallService`.

### Раскладка

Окно 760x580, две панели.

```
┌ СКРИПТЫ ЗВОНКОВ                                    X ┐
├─ [ поиск... ]        │  Возврат товара          ● Продажи
│  [Все][●Продажи][●…] │  Описание скрипта...
│                      │  ─────────────────────────────
│  ▾ Продажи           │  ШАГИ
│    ● Возврат товара  │  1. …  2. …
│    ● Отказ           │  ВОПРОСЫ
│  ▾ Поддержка         │  • …
│    ● …               │  ПОДСКАЗКИ
│                      │  • …
├──────────────────────┼───────────────────────────────
│                      │  Комментарий (необязательно)
│                      │  [ textarea, 3 строки        ]
├ Отмена                                    Сохранить ─┤
```

**Левая панель (~280px).** Поиск, ряд чипов категорий, дерево скриптов.
Состояния: «Загрузка…», «Не удалось загрузить скрипты» + кнопка «Повторить»,
«Нет доступных скриптов».

**Правая панель.** До выбора — плейсхолдер «Выберите скрипт слева». После
выбора — заголовок, цветной чип категории (`Category.Color`), описание, секции
«Шаги» (нумерованный список), «Вопросы», «Подсказки» (маркированные). Пустые
секции скрыты. Панель скроллится.

**Комментарий.** Закреплён под правой панелью, не уезжает при скролле.
Необязателен: пустой отправляется как `note: ""`.

### Поиск и фильтр

Матч по `Title`, `Description`, `Steps`, `Questions`, `Tips` (сейчас только
`Title`). Родитель, чей заголовок совпал, показывает всех активных детей —
поведение сохраняется. Чип категории — дополнительный фильтр поверх запроса;
чип «Все» сбрасывает.

### Клавиатура

- `Esc` — отмена
- автофокус в поле поиска при открытии
- двойной клик по узлу дерева — сохранить и закрыть

Кнопка «Сохранить» активна только когда выбран скрипт.

## Изменения

| Файл | Что |
|---|---|
| `Models/ScriptModels.cs` | `+ ScriptSelection { CallScript Script; string Note; }` |
| `Services/ScriptService.cs` | `GetScriptsAsync` возвращает `ScriptsResult` (список + текст ошибки); `RegisterScriptAsync(uniqueId, scriptId, note)`; `RegisterAndMarkAsync(uniqueId, selection)` |
| `Views/ScriptsDialog.axaml` | новая двухпанельная раскладка |
| `Views/ScriptsDialog.axaml.cs` | детали скрипта, фильтр категорий, состояния загрузки, комментарий |
| `Views/ActiveCallView.axaml.cs` | принять `ScriptSelection`, вызвать `RegisterAndMarkAsync` |
| `Views/RecentsView.axaml.cs` | то же |
| `Assets/i18n/{ru,kk,tg,uz}.json` | новые ключи |

### Новые ключи i18n

`ScriptSteps`, `ScriptQuestions`, `ScriptTips`, `ScriptComment`,
`ScriptCommentHint`, `ScriptPickHint`, `ScriptsLoading`, `ScriptsEmpty`,
`ScriptsLoadError`, `Retry`, `AllCategories`.

Существующие переиспользуются: `CallScripts`, `SearchScripts`, `Cancel`, `Save`.

## Вне объёма

- дописывание комментария к уже залогированному звонку из истории
- перевод диалога на MVVM
- редактирование/создание скриптов из виджета
